When recording audio, each sample is a measurement of the air pressure

In JUCE sample values are floating-point numbers between -1 and +1
ADC and DAC work with integers
16 bit = 65536 possible values
24bit = 16.8 million possible values

ADC must put continuous voltage reading
into decrete number with a limited number of bits.

It round off the voltage to the nearest whole number.
This process is **quantization** and it introduces an error names **quantization noise**

The more bits the smaller the effect of **quantization noise**

For plug-in programmer, this does not matter that much
32 bit single precision floats have precision of 24 bits
JUCE lets you use 64bit double precision floatin point if necessary.
At the end of the signal path, DAW can add **dithering**
which adds small amounts of noise into the sound on purpose.
