The host and plugin communicate also using **parameters**
For each of the knobs in the interface a parameter will be defined
which exposes the controls to the host

Make it possible to record automation.

Parameters are only to be used for settings of audio processing.

## state restoration
When user saves preset or project the plug in knobs would be at default position
Plugins handle this with:
`getStateInformation`: host asks the plug-in to save all its parameters values
`setStateInformation`: the host tells the plug-in that it should restore
its state from a previeously saved project.

Is common to JUCE save params values into XML
but plugin is free to chose how it saves data.

Plugin can also have factory presets, typically accessed through a
menu item in the window.
