In inspect properties, the host and plugin communicates each other using the APO questions:
`acceptsMidi`
`hasEditor`
`getNumPrograms`
`getLatencySamples`

Once the host understand what the plugin does
it sends the command `prepareToPlay`
This informs the plugin about the **sample rate** and **audio buffer** size to use

The counterpart of `prepareToPlay` is `releaseResources`
sent when the DAW has finished playing audio.

The most important is `processBlock`
This request is sent hundreds or thousands of times per second by the host app.
Is where the plug-in do all its work.

When the user removes the plugin from track
the **destructor** unloads the plugin from computer's memory
