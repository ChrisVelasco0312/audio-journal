`PluginProcessor.cpp` and `PluginProcessor.h`
Contain the code for `DelayAudioProcessor`
The part of the plug-in that will do the audio processing
It will receive audio from host
change it
send the processed audio back to the host

`PluginEditor.cpp` and `PluginEditor.h`
`DelayAudioProcessorEditor` object
which handles plug-in's UI
Will draw the knobs and buttons and text on the screen.
Allow user to interact with them.
