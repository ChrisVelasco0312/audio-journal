
## Plugin main components in JUCE

Two primary components:

##### The processor `AudioProcessor`: 
In charge of Audio and MIDI procesing.
manages audio parameters exposed to DAWS
Preset loading/saving
Reports metadata
Intantiates the editor.
##### The Editor `AudioProcessorEditor`:
Handle GUI display and user input
Receives referece to the processor.
Ui controls (knobs, sliders) can directly alter audio params.

> **Rule**: Never store audio-related state or DSP variables inside the editor
> as it can be destroyed at any time by the host while the processor is alive.

## Plugin Lifecycle

 **`createPluginFilter()`:** 
	 Called when user loads plugin onto a track.
	 Instantiates processor and returns a [[pointer]] to it
**`prepareToPlay(double sampleRate, int samplesPerBlock)`**:
	 Called before audio processing.
	 Provides essential sample rate $f_s$  and maximum block size.
	 Here [[allocate]] audio buffers.
**`processBlock(AudioBuffer<Type>& buffer, MidiBuffer& midiMessages)`**:
	 Real-time audio callback loop.
	 Host passes audio samples and MIDI data to be processed.
	 It **must** execute faster than the duration of the physical buffer
	 to prevent audio dropouts (glitches).
**`releaseResources()`**: 
	 Called when playback stops or the plugin is unloaded.
	 Use to clean up memory or release resources that are not needed.
**`createEditor()`**:
	 Triggered when the user opens the plugin's GUI window

## Defensive Programming in Real-Time

Different DAW(hosts) behave unpredictably.
Program defensively to prevent crashes.

**Memory Allocation**: 
	 Do not allocate or free memory on the audio thread. in `processBlock()`
**Buffer Sizes**
	 Host pass ocassionally buffers larger than `samplesPerBlock`	
	 specified in `prepareToPlay()`.
	 Safe practice: Allocate slightly largers buffers than requested,
	 And dynamically check incoming buffer size at runtime via `buffer.getNumSamples()`
**Tail Processing**
	 Host may continue valling `processBlock()`
	 even when playback is paused to let time-based effects flush naturally.
