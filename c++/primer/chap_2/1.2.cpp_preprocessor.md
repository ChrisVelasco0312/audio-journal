If your program is to use the usual c++ input output:
```cpp
#include <iostream>
using namespace std;
```

C++ uses a **preprocessor**
Is a program that processes a source file before the main compilation
`#include <iostream>` is a preprocessor directive.
This directive causes the preprocessor to add the contents of the `iostream`
file to your program.

A typical preprocessor action is adding or replacing text in the source code
before compilation

Why to add contents of **iostream** file to the program?

The **io** in **iostream** refers to **input**
which is info brought into the program and the outside world
and **output** which is info sent out from the program
The program need **cout** facility to display a message.

## Header filenames

Files such as **iostream** are called **include** files or **header** files.
C++ compilers come with many header files supporting a particular family of facilities.

## Namespaces

`using namespace std;` this is a **using** directive.
Namespace simplify the writing of programs that combine
preexisting code from several vendors.
Namespace lets a vendor package its wares in a unit called a namespace
so that you can use the name of a namespace to indicate which vendors product you want.

`Microslop` could place its definitions in `Microslop`namespace.
Then `Microslop::slopify()` would become the full name for `slopify()` function.

`cout` variable used for output and defined in `iostream` is called `std::cout`
and `endl` is `std::endline`
```cpp
std::cout << "This is a message...";
std::cout << std::endl;
```

You can make available just those names you need
with `using` declaration:
```cpp
using std::cout;
using std::endl;
using std::cin;
```

So you can use `cout` `endl` `cin` without attaching `std::`
