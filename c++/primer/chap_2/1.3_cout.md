
in
```cpp
cout << "Come up and C++ me some time.";
```
The part in double quotes is a **character string**
The `<<` notation indicates that statement is sending the string to `cout`
Symbols point the way information flows.
`cout` is a predefined object that knows how to display strings, numbers, characters.

The `cout` object, whose properties are defined in **iostream** file represent a stream.
The properties for `cout` include an insertion operator `<<`
that inserts info on its right into the stream.

> in C there is a bitwise left-shift operator `<<`
> The `cout` object uses **operator overloading**
> the same operator symbol can have different meaning.
