
## endl
```cpp
cout << endl;
```
`endl` is a special c+++ notation that represents beginning a new line
Causes the screen cursor to move to the beginning of the next line.
this is a **manipulator**
## newline char

```cpp
cout << "What's next?\n";
```
The `\n` combination is considered to be a single character called the **newline** character.
Is a example of special keystroke combinations termed "escape sequences"
