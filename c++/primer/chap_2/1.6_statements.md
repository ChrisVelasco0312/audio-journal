c++ program is a collection of functions
each function is a collection of statements.

There are several kinds of statements.
**declaration statement**: create a variable
**assignment statement**: provides a value for that variable.

```cpp
#include <iostream>

int main()
{
	using namespace std;
	
	int carrots; // declare integer variable
	carrots = 25; // assign a value to the variable
	
	cout << "I have " 
	<< carrots // display the value of the variable
	<< " carrots."
	<< endl; 
	
	carrots = carrots - 1 // modify the variable
	cout << "Crunch, crunch. Now I have " << carrots << " carrots." << endl;
	
	return 0;
}
```
## Declaration Statements and Variables

To store an item in a computer
identify the **storage location** and how much **memory** space requires.

In c++ use **declaration statement**: indicates the type of storage and a label for the location.
`int carrots;`
**int** type can be positive or negative.
size depends on the implementation.
`carrots` is a variable because you can change its value.
You must declared all variables.

Is called **defining declaration** or **definition**
The compiler allocate memory space for the variable.

In C or Pascal, all variable declarations come at the very beginning of a function.
C++ has no such restriction.
You can declare a variable before it is first used.
> declare variables as close to its first use as possible
