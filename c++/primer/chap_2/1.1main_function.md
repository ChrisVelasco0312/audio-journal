Programs are constructed with building blocks called **functions**
### main() function
```cpp
int main()
{
	statements
	return 0;
}
```

Above is a **function definition** with two parts
`int main()` is the **function header.**
`{}` the portion enclosed in braces is the **function body**
Each complete instruction is called **statement**, must terminate with semi-colon.

The **return statement** terminates the function.

> never omits semicolon in c++

#### about functions
a c++ function is **called** by another function, and the function header
describes the **interface** between a function and the function that calls it.

The part preceding the function name is the **function return type** `int ...`
it describes information flow from a function back to the function that calls it.

The part within the parenthesis `()` is called the **argument list** or **parameter list**
describes info flow from the calling function to the called function.

`main()` is called by startup code that compiler add to the 
program to mediate between it and the operating system.
The function header describes the interface between `main()` and OS

A c++ function called by another function can
return a value to the activating calling function
The value is called **return value**

`int main()` can return an integer value.
empty parenthesis mean `main()` function takes no info.
or no arguments.
