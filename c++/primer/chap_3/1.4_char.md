`char` is designed to store characters.
The most common symbol set in US is ASCII character set.
A numeric code represents each char in the set.
65 is for the char A.
77 is the code for M.

```cpp
//morechar.cpp
#include <iostream>
int main()
{
	using namespace std;
	char ch = 'M';
	int i = ch;
	cout << "The ASCII code for " << ch << " is: " << i << endl;
	cout << "Add one to the character code:" << endl;
	ch = ch + 1;
	i = ch;
	cout << "The ASCII code for " << ch << " is " << i << endl;
	
	// using cout.put() to display a char constant
	cout.put('!');
	cout << endl << "Done" << endl;
	return 0;
}
```

## a member function `cout.put()`

`cout.put()` has a point because it is a **member function**
A member function belongs to a class and describes a method for manipulating class data.
`ostream` class has `put()` member function designed to output characters.
You can use a member function only with a particular object of that class such as cout
