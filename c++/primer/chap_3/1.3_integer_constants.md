**integer constant** is one you write out explicitly
such as 212 or 1776.

C++ lets write them in three different number bases:

- base 10: decimal
- base 8: octal
- base 16: hexadecimal

C++ uses the first digit or two to identify the base.

- if first digit is in the range 1-9, number is base 10 (decimal)
thus 93 is base 10
- if first digit is 0 and second is in the range 1-7, number base in 8 (octal)
thus 042 is octal and equal to 34 decimal.
- If the first two chars are 0x or 0X the number base is 16 (hexadecimal)
thus 0x42 is hex and equal to 66 decimal
for hexadecimal values.
chars a-f and A-F represents hexadecimal digits
corresponding to  values 10-15.
0xF = 15
0xAF = 165 (10 sixteens plus 5 ones)

[[binary_hexadecimal]]

```cpp
//hexoct1.cpp
#include <iostream>
int main()
{
	using namespace std;
	int chest = 42;
	int waist = 0x42; //hex
	int inseam = 042; // octal
	
	cout << "Monsieur  cuts a striking figure!\n";
	cout << "chest = " << chest << "\n";
	cout << "inseam = " << inseam << "\n";
	
	return 0;
}
```

by default cout displays integers in decimal form.
To display a value in hexadecimal or octal
use special features of **cout**

Use **hex**, **oct**, and **dec** manipulators.
```cpp
#include <iostream>
using namespace std

int main()
{
	int chest = 42;
	int waist = 42;
	int inseam = 42;
	
	cout << chest << (decimal) << endl;
	cout << hex;
	cout << waist << endl;
	cout << oct;
	cout << inseam << endl;
	return 0;
}
```
