`const int MONTHS = 12;` MONTHS is **symbolic constant** for 12
The compiler does not let you change the value MONTHS
The keyword `const` is a qualifier because it qualifies the meaning of a declaration.

`const type name = value;`
It should be initialized.

**const** in cpp

Lets you specify the type explicitly.

you can use C++ scoping rules to limit the definition to
particular functions or files.

you can use const with more elaborate types, such as arrays and structures.
