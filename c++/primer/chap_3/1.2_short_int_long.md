Systems use the minimum guarantee:
**short** 16bits
**long** 32bits

Typically **int** is 16 bits (the same as short)

```cpp
short score;
int temperature;
long position;
```

All of them are signed types.
its range approximately equally between positive and negative.
16bit -> -32768 to +32767

**tools to know the systems integers size**
the `sizeof` operator returns the size, in bytes, of a type or a variable.
`climits` header file contains info about integer type limits.
define symbolic names to represent different limits.
`INT_MAX` as the largest possible int
`CHAR_BIT` as the number of bits in a byte.

```cpp
// limits.cpp
#include <iostream>
#include <climits>
int main()
{
	using namespace std;
	int n_int = INT_MAX;
	short n_short = SHRT_MAX;
	long n_long = LONG_MAX;
	
	cout << "int is " << sizeof (int) << " bytes." << endl;
	cout << "short is " << sizeof n_short << " bytes." << endl;
	cout << "long is " << sizeof n_long << " bytes." << endl << endl;
	
	cout << "Maximum values: " << endl;
	cout << "int: " << n_int << endl;
	cout << "short: " << n_short << endl ;
	cout << "long: " << n_long << endl << endl;
	
	cout << "Minimum int value = " << INT_MIN << endl;
	cout << "Bits per byte = " << CHAR_BIT << endl;
	
	return 0;
 }
```

## sizeof operator

When use `sizeof` with a type name, such as `int` use `()` : `sizeof (int)`
When use `sizeof` with variable name, parenthesis are optional: `sizeof n_short`

`climits` file defines symbolic constants to represent type limits.
`INT_MAX` is the largest value `int` can hold.

## initialization

C++ has a second initialization syntax:
```cpp
int owls = 101; // traditional C initialization
int wrens(342); // alternative c++ syntax.
```

### unsigned

`unsigned` versions of variables represent only non-negative values
```cpp
unsigned short change;
unsigned int rovert;
unsigned quarterback;
unsigned long gone;
```

### Which to choose

`int` is set to the most "natural" integer size:
integer form that computer handles most efficiently.

if a variable represent non-negative, use `unsigned`
for portability use `long for bit integers q`
