Systems use the minimum guarantee:
**short** 16bits
**long** 32bits

Typically **int** is 16 bits (the same as short)

```cpp
short score;
int temperature;
long position;
```

All of them are signed types.
Each pslits its range approximately equally between positive and negative.
16bit -> -32768 to +32767

**tools to know the systems integers size**
the `sizeof` operator returns the size, in bytes, of a type or a variable.
`climits` header file contains info about integer type limits.
define symbolic names to represent different limits.
`INT_MAX` as the largest possible int
`CHAR_BIT` as the number of bits in a byte.
