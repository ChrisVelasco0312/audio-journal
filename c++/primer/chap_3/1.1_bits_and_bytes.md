
**bit** is the fundamental unit.
An 8 bit chunk of memory can be set to 256 different combinations.
256 = 2 x 2 x 2 x 2 x 2 x 2 x 2 x 2 -> one bit has two possible values 1 or 0
Each additional bit doubles the number of combinations.
16bit = 65536 different values.
32bit = 4,294,672,296

A byte means an 8bit unit of memory. 
Kylobyte = 1,024 bytes
Megabyte = 1,024 kilobytes.

C++ defines `byte` differently
C++ byte consist of at leas enough adjacent bits to accomodate
the basic character set for the implementation.
The number of possible values must equal or exceed the number of distinct characters
Basic char sets as ASCII and EBCDIC sets.
Each can be accommodated by 8bits.
A c++ byte is 8 bits on systems using those char sets.
International programming can require much larger sets -> Unicode.
Some implementations may use 16 bit byte or 32-bit byte.
