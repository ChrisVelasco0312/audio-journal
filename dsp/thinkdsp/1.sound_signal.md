A **signal** is a quantity that varies in time.
**Sound** is variation in air pressure.
**Sound signal** represents variations in air pressure over time

**Microphone** measures these variations and generate electrical signal represents sound.
A **speaker** takes an electrical signal and produces sound

**Microphones** and **Speakers** are **transducers**
They transduce or convert signals from one form to another.

## Periodic signals

Signals that repeat themselves after some period of time

A **sinusoid** signal, has the same shape as the trigonometric sine function.
Is a periodic signal, and we call repetitions as **cycles**

The duration of each cycle is called the period: 2.3ms

**Frequency** is the number of cycles per second, the inverse of the period.
Unit is **Hertz** or **Hz**

A tuning fork generates a sinusoid because
the vibration of the tines is a form of simple harmonic motion.

![[violin_signal.png]] 

Above is a violin recorded signal. The signal is periodic but the shape is complex.
The shape is called the **waveform**
The shape of the waveform determines the musical **timbre**

## Spectral decomposition

The idea that any signal can be expressed as the sum of sinusoids with different frequencies.
Can be represented by **discrete Fourier transform** or **DFT**: Takes a signal and produces its **spectrum**

The **spectrum** is the set of sinusoids that add up to produce the signal.
The algorithm is the **Fast Fourier transform FFT**, which is an efficient way to compute DFT

![[spectrum_violin.png]]
The figure shows spectrum of the violin record
x-axis is the range of frequencies that make up the signal.
y-axis shows the strength or **amplitude** of each frequency component.

Lowest frequency is **fundamental frequency**.
The fundamental of this signal is 440hz

In the signal, the fundamental has the largest amplitude. 
It is the **dominant frequency**
The perceived pitch of a sound is determined by the fundamental,
even if it is not **dominant**.

The other spikes are 880, 1320, 1760 and 2200.
Which are integer multiples of the fundamental.
These are called **harmonics** because are musically harmonious with the fundamental.

- 880 is A5, one octave higher than the fundamental. Octave double the frequency.
- 1320 is E6 aprox. A perfect fifth above A5.
- 1760 is A6, two octaves above fundamental.
- 2200 is c#7, a major third above 6.

Given harmonics and their amplitudes, you can reconstruct the signal by adding up sinusoids.

## Signals

**thinkdsp.py** contains classes and functions for working with signals and spectrums.

Provides a class `Signal`, which is the parent class of signal types like `Sinusoid`
which represents sine and cosine signals.

```python
cos_sig = thinkdsp.CosSignal(freq=440, amp=1.0, offset=0)
sin_sig = thinkdsp.SinSignal(frequ=880, amp=0.5, offset=0)
```

`freq` is frequency in Hz
`amp` is amplitude in unspecified units. 1.0 is the largest amplitude.

`offset` is **phase offset** in radians. 
**Phase offset** determines where in the period the signal starts.
A sine signal with offset=0 starts at sin 0, which is 0.
With offset=pi/2 it starts at $sin \pi/2$ which is 1 |> _clarify this later_


Signals have an __add__ method, we can use + operator to add them:
```python
mix = sin_sig + cos_sig
```

_read further [add magic method in python](https://www.geeksforgeeks.org/python/python-__add__-magic-method/)_

Result is `SumSignal` the sum of two or more signals.
Is a Python representation of a mathematical function.

Most Signals are defined for all values ot t, from negative infinity to inginity.

**Evaluate** means taking a sequence of point in time , `ts` and `ys` using NumPy arrays
and encapsulate them in an object called **Wave**

**Wave** represents a signal evaluated at a sequence of points in time.
Each point in time is called a **frame**
The measurement is called a **sample**

**Signal** provides  **make_wave** which returns a new Wave object
```python
wave = mix.make_wave(duration=0.5, start=0, framerate=11025)
```

- `duration`: length of the Wave in seconds
- `start` start time in seconds.
- `framerate` the integer number of frames per second.

11,025 frames per second is a **framerate** used in formats like WAV and mp3

example evaluates signal: from t=0 to t=0.5 at 5513 equally-spaced frames (11025/2)

Wave has **plot** method that uses pyplot
```python
wave.plot()
pyplot.show()
```

```python
period = mix.period

```

## Reading and writing waves

**read_wave**, reads a WAV file and returns a Wave:
```python
violin_wave = thinkdsp.read_wave('input.wav')
```
and **Wave** provides **write** which writes a wav file.
```python
wave.write(filename='output.wav')
```

**play_wave** runs media player as a subprocess
```python
thinkdsp.play_wave(filename='output.wav', player='aplay')
```

## Spectrums

**Wave** has **make_spectrum** which returns a **Spectrum**:
```python
spectrum = wave.make_spectrum()
spectrum.plot()
```

**3 methods** to modify the spectrum:
- **low_pass**: applies low-pass filter, which means components above a given cutoff frequency are attenuated (reduced in magnitud) by a factor
- **high_pass**: applies a low-pass filter, which attenuates components below the cutoff.
- **band_stop**: attenuates components in the band of frequencies between two cutoffs.

```python
spectrum.low_pass(cutoff=600, factor=0.01)
```
